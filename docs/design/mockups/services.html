General settings are not drawn in this mockup. The four v0.1 screens are the scope.

Only the system tag namespaces ship in v0.1: type:, format:, source:, quality:, indexer:. They render as chips you can filter by but not delete. Aliases, virtual parents and the rule engine are v1.0.

Theme and density live in the top bar of every screen, and both persist. There is no colour-impaired mode setting, because every status here is an icon and a word as well as a colour.
